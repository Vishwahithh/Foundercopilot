# Founder Copilot

Research, positioning and the original landing page for a tool that helps founders turn their
own customer calls and interviews into messaging and distribution content.

The product now lives at [foundercopilot.co](https://foundercopilot.co) (separate Next.js
codebase). This repo is the thinking that came before it, kept because the thinking is the
useful part.

## What is here

| Folder | Contents |
|---|---|
| `Docs_and_Research/` | Idea validation memo, internal product clarity doc (thesis, explicit non-goals, scope), MVP PRD, implementation PRD, and the founder pain-point research behind them |
| `Frontend_Variants/` | The static landing page (`index.html`), two copy variants for A/B testing, and ten SEO pages under `learn/` and the workflow subfolders |
| `Design_Inspiration/` | References used for the visual direction |
| `promo-video/` | Assets for the launch clip |

## The honest state

The positioning doc and MVP spec are strong: a clear thesis, explicit non-goals, disciplined
scope. The landing page and waitlist form shipped. The product behind them, the pipeline that
ingests a transcript and generates messaging, was never built in this repo, and the landing page
was never distributed. It did not fail distribution, it never ran distribution.

What came out of it: the positioning work fed directly into the systems case studies and the
directory pivot at foundercopilot.co.

## Run the landing page

Open `Frontend_Variants/index.html` in a browser. No build step.
